Security

Compromised production server: root cause and hardening

Remediation

A client's ERP server was slow and unstable because of unauthorized software running on it. I traced the cause to an internet-exposed demo database with weak access control, then reduced the server's exposure.

  • Did the root-cause analysis and identified the vulnerability and the way in.
  • Closed public access to the Odoo application and WebSocket ports and reviewed and tightened folder permissions.
  • Planned operating system security patching and told stakeholders about maintenance windows and precautions.
  • Reviewed SSH and AWS IAM access, rotated SSH keys during an employee offboarding, and checked SSL, Nginx and domain configuration.
  • Evaluated Cloudflare as an added protection layer in front of the domain.

ScopeRemediation and hardening on a live server. This was not a forensic engagement.

What it showsPractical hardening, exposure reduction and access management on live servers.
